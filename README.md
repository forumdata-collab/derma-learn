# 皮紋分析學習站 🔎

皮紋（Dermatoglyphics）是指人類手指、手掌與足底的凹凸紋理。本站以教育目的梳理指紋的基本結構、皮紋分析的理論與應用、以及科學界的批評，讓學習者以批判角度理解此領域。

## 🎯 教學內容

三個漸進式學習程度：

- **🌱 入門級**：指紋形成、三大基本紋型（弧形/箕形/斗形）、三叉點與核心點
- **🔥 進階級**：皮紋學歷史、十指對應大腦（業者觀點）、TRC/Atd 角指標、MME-DAK 兒童評估應用
- **🧭 研究級**：已驗證事實 vs 有爭議主張、DAK 研究方法學分析、科學批評、批判思考框架

每個程度含：教學目標 + ELI5 內容 + 示範圖 + 5 題即時評分選擇題。
